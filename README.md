# 경구약제 이미지 객체 검출(Object Detection) 프로젝트

컨베이어벨트·모바일 환경에서 실시간 알약 탐지를 위한 YOLO 기반 객체 검출 모델 개발 프로젝트입니다. (5인 팀)

**기간**: 2025.07.15 – 2025.07.31

**담당**: 데이터 EDA 및 어노테이션 정합성 검증

---

## 담당 업무: EDA 및 데이터 품질 진단

약품별 폴더에 흩어진 학습 어노테이션 4,526건(이미지 1,257장·73종)의 개별 JSON을 COCO 통합 포맷으로 병합하는 코드를 작성하고, 이를 기반으로 데이터 품질을 전방위로 진단했습니다.

**COCO 포맷 통합 코드 작성**

개별 JSON 파일을 images/annotations/categories 구조로 병합하는 변환 코드 구현

**COCO→YOLO 포맷 변환 스크립트 작성**

YOLOv8 학습에 필요한 라벨(txt)+yaml 생성 자동화

**EDA (탐색적 데이터 분석)**

이미지·객체 수 분포, 73개 클래스 간 데이터 불균형(어노테이션 5개 이하 클래스 식별) 시각화

**어노테이션 정합성 검증**

팀 공용 분석 도구(bbox 뷰어/에디터, 약품코드별 이미지 뷰어)를 활용해 객체 겹침, 약품코드-라벨 불일치, 잘못된 bbox 좌표를 직접 검토·수동 판별

---

## 개인 탐색: YOLOv8 모델 사이즈별 비교 테스트

공식 역할(EDA)과 별개로 진행한 개인 실험입니다.

- 동일 학습 조건(20 epoch, imgsz 640, batch 16)에서 YOLOv8 l / m / s 3개 사이즈를 비교 학습
- mAP·Recall 기준 YOLOv8s가 가장 우수했습니다 (mAP 0.360 · Recall 0.913, 단일 실행)
- 팀 모델링(팀원 담당)은 v8n을 기준으로 v8s·v8x와 비교한 뒤, 이미 성능이 포화돼 비용 대비 이점이 작다고 보고 v8n을 최종 채택했습니다 (mAP@0.5 0.995는 v8n·batch 8·증강 설정)
- 개인 실험은 모델 범위(v8n 미포함)와 학습·평가 조건이 달라 팀 결과와 별개입니다
